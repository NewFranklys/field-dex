# Species Record 2.0 — visual language plan

This branch expands the FIELD DEX visual language without changing the product architecture.

Planned scope:

- canonical 18-type icon system, sourced from the MIT-licensed `partywhale/pokemon-type-icons` vector recreation and stored locally in FIELD DEX;
- type icons in species badges, archive cards/filters, type observatory and matchup chips;
- connected evolution timeline with methods presented between stages where the family is linear, while preserving branching-family correctness;
- visual size comparison using a neutral human silhouette and Pokémon height;
- historical sprite archive from PokéAPI version sprite data when available;
- stronger visual treatment for the Types observatory;
- light metadata/contrast polish for readability;
- keep EN/PT-BR and all existing routes/behavior intact.

This phase does not add National Dex, game-specific encounter data, accounts, TCG or forms browsing.
